# NumPy Tutorials

This repository contains my notes and practice notebooks while learning **NumPy**. It covers the fundamental concepts of NumPy through examples and hands-on exercises, helping build a strong foundation for Data Science and Machine Learning.

## Topics Covered

- Speed Test (Python vs NumPy)
- Introduction to NumPy
- Creating NumPy Arrays
- Indexing and Slicing
- Practice Exercises
- Multidimensional Arrays
- Data Types
- Broadcasting
- Mathematical Functions

## Tech Stack

- Python
- NumPy
- Jupyter Notebook

## Getting Started

Install the required packages:

```bash
pip install numpy jupyter
```

Clone this repository and open the notebooks using Jupyter Notebook or Visual Studio Code.
